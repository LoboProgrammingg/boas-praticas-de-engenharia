# Boas Práticas de Engenharia

Guia prático de boas práticas de engenharia de software e segurança, com exemplos
testados em Python e TypeScript. Por [Matheus Lobo](https://github.com/LoboProgrammingg).

> Em construção: cada seção chega por um Pull Request revisado e com CI verde.

## Como rodar os exemplos

```bash
uv sync                 # Python 3.12+
uv run pytest
./scripts/typecheck.sh

npm ci                  # Node 22+
npm run typecheck && npm test
```
