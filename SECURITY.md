# Política de segurança

Este repositório contém exemplos educacionais. Os arquivos `vulneravel.py` são
**intencionalmente inseguros** e existem para ensinar; não os use em produção.

## Como reportar

Encontrou uma falha real (por exemplo, um exemplo `seguro.py` que não é seguro, ou um
problema no CI)? Reporte de forma **privada** pelo
[GitHub Security Advisories](https://github.com/LoboProgrammingg/boas-praticas-de-engenharia/security/advisories/new).
Não abra issue pública.

Inclua: arquivo afetado, descrição do problema e, se possível, como reproduzir.

## Prazos

| Etapa | Prazo |
|---|---|
| Confirmação de recebimento | até 3 dias úteis |
| Avaliação inicial | até 10 dias úteis |
| Correção e divulgação coordenada | conforme a gravidade |

## Versões suportadas

Apenas a versão mais recente da branch `main`.
